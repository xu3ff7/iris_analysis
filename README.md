\# Iris Dataset Analysis



\## Project Setup



This project was created using uv.



To run the project:



1\. Install dependencies:

uv sync



2\. Run Jupyter Notebook:

uv run jupyter notebook





\## Dataset



The project uses the Iris dataset stored in:

data/iris.csv





\## Analysis Summary



\- The dataset contains 150 rows and 5 columns.

\- There are 3 Iris species:

&#x20; - setosa

&#x20; - versicolor

&#x20; - virginica

\- No missing values were found.

\- One duplicate row was detected.

\- Species summary statistics were calculated using groupby().

\- Filtered datasets were exported to CSV files.





\## Output Files



\- output/species\_summary.csv

\- output/filtered\_iris.csv
